## 📋 Descripción

Sistema de gestión de inventario para una ferretería, desarrollado en Python. Permite administrar productos mediante un menú interactivo por consola.

## ⚙️ Funcionalidades

- Agregar productos al inventario
- Consultar stock por producto
- Actualizar cantidades
- Eliminar productos
- Mostrar el inventario completo

## 📌 Restricciones del examen

El ejercicio fue resuelto respetando las siguientes restricciones impuestas por la cátedra:

- Solo listas paralelas (sin diccionarios ni estructuras avanzadas)
- Sin uso de `try/except`
- Menú implementado con bucle `while`
